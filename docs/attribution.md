# Attribution

- First touch assigns 100% to the earliest eligible touchpoint.
- Last touch assigns 100% to the final eligible touchpoint before conversion.
- Linear divides credit equally; remainder cents are assigned deterministically to the final touchpoint.
- U-shaped assigns 40% to the first touch, 40% to the final touch and distributes 20% across the middle.

Attribution is a model, not causal proof. The UI exposes model disagreement and source completeness so users can judge confidence.
