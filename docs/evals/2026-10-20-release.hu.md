# GitHub és Vercel kiadás – 2026. október 20.

A kiadás egyesíti az `e5804cc` analitikai javításait, a `dac7ed5` feltöltési kizárásait és a GitHubon közben megjelent, `44c35ad`-ig tartó négy jelszó-visszaállítási commitot.

Az új jelszóoldalak kiadási ellenőrzése során javítottuk a keresési paraméterek Suspense-kezelését és a visszaállítási token egyszer használhatóságát párhuzamos kéréseknél. A visszaállítási hivatkozás nem kerül naplóba. Levélküldő nincs implementálva vagy konfigurálva: a kérés egyértelmű hibát ad, nem generál tokent, és nem állítja, hogy e-mailt küldött. A funkció teljes használatához még szükséges a levélküldés megvalósítása.

Az egyesített forráson sikeres ellenőrzések:

- Production build és TypeScript.
- ESLint.
- 104 unit-/integrációs teszt, 11 tesztfájl.
- 2 új Playwright-szcenárió: hiányzó levélküldés őszinte jelzése, valamint hiányzó/érvénytelen visszaállítási token elutasítása.

A korábbi 16 Playwright-szcenárió és 8 motor-eval eredménye a külön javítási jelentésben szerepel; ezek nem újrafuttatott eredmények. A helyi ellenőrzések nem igazolják önmagukban a GitHub CI vagy a Vercel telepítés állapotát.
