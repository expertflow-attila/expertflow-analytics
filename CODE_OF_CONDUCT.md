# Code of conduct

## The short version

Be straightforward and be kind. Disagree about the work, not the person.

## Expected behaviour

- Assume good faith
- Give specific, actionable feedback
- Accept that maintainers may decline a change, and say why
- Respect that contributors work in different timezones, languages and levels
  of experience

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, publishing others'
private information, or sustained disruption of discussion.

## Enforcement

Report concerns to the repository maintainers through a private GitHub
security advisory or by contacting the repository owner directly. Reports are
handled confidentially. Maintainers may edit, remove or reject contributions
and comments that breach this policy, and may block repeat offenders.
